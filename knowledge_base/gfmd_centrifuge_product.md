## Product Overview
The Silencer Centrifuge by GFMD is the quietest centrifuge on the market, designed for hospital labs, clinical laboratories, university research labs, and pharmacy compounding facilities. It delivers reliable, high-performance sample processing while significantly reducing lab noise levels.

## Hyperdrive System (All Models)
All Silencer centrifuges feature the unique Hyperdrive system:
- Brushless DC Motor
- Simultaneous Digital RPM and RCF Display
- Digital Time Display
- Timer Range 1-999, plus hold
- Save and Recall up to 3 speed and time configurations
- Lockable Settings
- Nine Selectable Dynamic Braking Levels, plus off (N/A on MACH)
- User Selectable Energy Saving Mode
- On Error Displays Error Number with Explanation
- Completely Enclosed Rotor Chamber
- See-Through High-Strength Lid
- Dual Safety Interlock System -- Ensures Lid is Closed and Locked
- Audible End-of-Run Indicator -- User defined 1-9 tones
- Spill-Resistant Control Panel
- Direct-Drive System

- Includes a Lid-Release Tool, free technical support, set-up assistant, and warranty

## End-of-Run Light (Patented Feature)
- A first in the industry -- only necessary on Silencers because they are so quiet
- Displays Red while running
- Blinks Green for 10 seconds when unit stops
- Displays Green at standby for the set time
- Blinks Red while stopping after speed drops below 500 RPM
- Set time can be 0 to 99 minutes or continuous
- Can be turned off by pressing the down button
- Alternates between Red and Green in case of an error
- Available as add-on: Part 2100-903 (MACH/ELITE), Part 2200-903 (STEALTH/TANK/ROVER)
